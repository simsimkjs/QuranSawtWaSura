# القرآن الكريم صوت وصورة — QuranSawtWaSura

مشروع JavaFX (Maven) — افتحه في NetBeans عبر **File → Open Project**.

## ⚠️ التصميم الحالي: نص فقط، بلا صور

تم إلغاء فكرة صور صفحات المصحف نهائيًا. عرض السورة الآن **نص عربي داخل إطار مزخرف** يحاكي شكل صفحة المصحف، كله برمجيًا عبر CSS/JavaFX بدون أي ملف صورة خارجي:

- التظليل أثناء التلاوة يطبَّق **مباشرة على النص نفسه** (دقيق 100%، لا يحتاج أي إحداثيات مسبقة).
- ما فيه حاجة لأي صور PNG/JPG لكل سورة، ولا أداة تحديد مناطق، ولا ملفات ربط.
- إضافة سورة جديدة = فقط ملف JSON (نص + توقيت) + ملف صوت، بدون أي صورة.

## التشغيل

1. تأكد أن مجلد `quran-data/` موجود **بجانب `pom.xml` مباشرة**.
2. شغّل من NetBeans (Run File على `QuranApp.java`) أو `mvn javafx:run`.

**المتطلبات:** JDK 17+ و JavaFX 21 (يُحمَّل تلقائيًا عبر Maven). نقطة الدخول: `sim.quran.QuranApp`.

## نسخة الويب

توجد نسخة ويب مستقلة في مجلد `web/` (HTML/CSS/JS بدون أدوات بناء) تقرأ نفس مجلد `quran-data/`،
وتعمل على الحاسوب والجوال: قائمة السور والتصفية، التلاوة المتزامنة مع تظليل الآية، الانتقال المباشر،
التصفّح (أجزاء/أحزاب/أرباع)، البحث، العلامات، التفسير، «مشواري مع القرآن»، والإعدادات — مع حفظ محلي
في المتصفح (`localStorage`). وتعرض الآيات بخط quran.com نفسه (نصوص QCF وخط لكل صفحة مصحف،
مع الخط العثماني الموحّد كخط أساسي واحتياطي).

```powershell
.\web\serve.ps1            # ثم افتح http://localhost:8000/web/
```

> استخدم خادمًا يدعم **HTTP Range** (مثل `web/serve.py` أو `npx serve`)، لأن ملفات الصوت كبيرة
> ويحتاج المتصفح للقفز داخلها. `python -m http.server` لا يدعم Range.
>
> لا تفتح `web/index.html` مباشرة عبر `file://` (يمنع المتصفح تحميل ملفات JSON).

بعد إضافة/حذف/تعديل سورة أو ملف صوت أو تفسير، أعد توليد فهارس البيانات:

```powershell
python tools\build_quran_data.py
```

يُنشئ `quran-data/manifest.json` (توفّر النص/الصوت/التفسير) و`quran-data/search-index.json`
(فهرس البحث المسبق). للتحقق دون كتابة: `python tools\build_quran_data.py --check`.

أما نصوص وخطوط QCF المطابقة لـ quran.com فتُولَّد بأمر مستقل:

```powershell
python tools\build_qcf_data.py
```

ويضيف `qcf`/`qcf_page` لكل آية، وينزّل خطوط الصفحات إلى `web/assets/fonts/qcf/`، ويكتب
`web/css/qcf-fonts.css`، ثم يحدّث فهارس البيانات تلقائيًا. للتحقق: أضف `--check`.
اختبارات الويب (Playwright) موجودة في `web/` وتعمل أيضًا عبر GitHub Actions.

التفاصيل الكاملة: [`web/README.md`](web/README.md).

## نمطا التصميم والثيمات

التطبيق يقسم المظهر إلى مفهومين منفصلين:

- **نمط التصميم (Design Style):** ملف CSS كامل مختلف.
  - `CLASSIC_MUSHAF` — «كلاسيكي (المصحف المزخرف)» عبر `src/main/resources/sim/quran/css/app2.css` (الافتراضي).
  - `MODERN` — «معاصر» عبر `src/main/resources/sim/quran/css/style.css`.
- **الثيم اللوني (Theme):** `CLASSIC` (رَقّي) / `LIGHT` / `DARK` — ويعمل **مع النمط الكلاسيكي فقط** (يُعطَّل تلقائيًا عند اختيار «معاصر»).

كلاهما يُحفظ في `settings.json` الخاص بالقارئ النشط.

## هيكلية `quran-data/`

```
quran-data/
├── surahs.json              فهرس الـ 114 سورة
├── manifest.json            (مُولَّد) توفّر النص/الصوت/التفسير لكل سورة
├── search-index.json        (مُولَّد) فهرس البحث المسبق لنسخة الويب
├── quran/
│   ├── 001.json             ← مرفق (الفاتحة)
│   └── 002.json ... 114.json   بنفس صيغة quran-ayah-splitter-project
├── audio/
│   ├── 001.mp3                ← مرفق (الفاتحة)
│   └── 002.mp3 ... 114.mp3
├── tafsir/                    (اختياري)
│   └── 001.json ...
├── images/                    ⚠️ قديم - غير مستخدم (نهج الصور مُلغى)
└── regions/                   ⚠️ قديم - غير مستخدم (نهج الإحداثيات مُلغى)
```

بمجرد وضع الملف الثنائي (json + mp3) بنفس رقم السورة (%03d)، يعمل تلقائيًا دون أي تعديل كود.
أما نسخة الويب فتقرأ `manifest.json` لمعرفة السور المتوفرة، لذا شغّل
`python tools/build_quran_data.py` بعد أي تغيير في البيانات.

**السور المرفقة حاليًا في البيانات:** 1، 2، 3، 4، 13، 14، 15، 16، 17، 18، 40.

### مواقع البيانات المحلية

يتعرف `DataPaths` على مجلد `quran-data` تلقائيًا (أو عبر خاصية النظام `-Dquran.data.dir=...`).

بيانات كل **قارئ** (إعدادات + علامات + تقدّم) تُخزَّن خارج المشروع في:

```
<مجلد المستخدم>/.quran_sawt_sura/
├── profiles.json            فهرس القرّاء + آخر قارئ نشط
└── profiles/<id>/
    ├── settings.json        الخط/الحجم/الثيم/نمط التصميم
    ├── bookmarks.json       العلامات المرجعية + آخر موضع
    └── progress.json        "مشوار حفظ القرآن"
```

## التفسير (ابن كثير / الجلالين)

لم تُرفع ملفات التفسير الفعلية بعد. `TafsirLoader` جاهز لاستقبالها بصيغة:

```json
{
  "source": "ابن كثير",
  "ayahs": [ { "ayah_number": 1, "text": "نص التفسير..." } ]
}
```
توضع في `quran-data/tafsir/001.json` وهكذا.
