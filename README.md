# القرآن الكريم صوت وصورة — QuranSawtWaSura

مشروع JavaFX (Maven) — افتحه في NetBeans عبر **File → Open Project**.

## ⚠️ التصميم الحالي: نص فقط، بلا صور

تم إلغاء فكرة صور صفحات المصحف نهائيًا. عرض السورة الآن **نص عربي (خط Amiri) داخل إطار مزخرف** يحاكي شكل صفحة المصحف (حدود ذهبية مزدوجة، خلفية بلون الرَّق القديم، دوائر زخرفية برقم كل آية بالأرقام العربية) — كله برمجيًا عبر CSS/JavaFX، بدون أي ملف صورة خارجي. هذا أبسط بكثير من نظام الصور والإحداثيات القديم:

- التظليل أثناء التلاوة يطبَّق **مباشرة على النص نفسه** (دقيق 100%، لا يحتاج أي إحداثيات مسبقة).
- ما فيه حاجة لأي صور PNG/JPG لكل سورة، ولا أداة تحديد مناطق، ولا ملفات ربط.
- إضافة سورة جديدة = فقط ملف JSON (نص + توقيت) + ملف صوت، بدون أي صورة.

## التشغيل

1. تأكد أن مجلد `quran-data/` موجود **بجانب `pom.xml` مباشرة**.
2. شغّل من NetBeans (Run File على `QuranApp.java`) أو `mvn javafx:run`.

## هيكلية `quran-data/`

```
quran-data/
├── surahs.json              فهرس الـ 114 سورة (مرفق كاملاً)
├── quran/
│   ├── 001.json             ← مرفق (الفاتحة)
│   └── 002.json ... 114.json   أضفها بنفس صيغة quran-ayah-splitter-project
├── audio/
│   ├── 001.mp3                ← مرفق (الفاتحة)
│   └── 002.mp3 ... 114.mp3
└── tafsir/                    (اختياري)
    └── 001.json ...
```

بمجرد وضع الملف الثنائي (json + mp3) بنفس رقم السورة (%03d)، يعمل تلقائياً دون أي تعديل كود.

## التفسير (ابن كثير / الجلالين)

لم تُرفع ملفات التفسير الفعلية بعد. `TafsirLoader.java` جاهز لاستقبالها بصيغة:

```json
{
  "source": "ابن كثير",
  "ayahs": [ { "ayah_number": 1, "text": "نص التفسير..." } ]
}
```
توضع في `quran-data/tafsir/001.json` وهكذا.

## الميزات المُنفَّذة

| الميزة | الحالة |
|---|---|
| نص الآيات داخل إطار مزخرف يحاكي صفحة المصحف | ✅ |
| تظليل الآية الحالية أثناء التلاوة (مزامنة start_ms) على النص مباشرة | ✅ |
| دوائر زخرفية برقم كل آية (أرقام عربية) | ✅ |
| تكرار الآية الحالية للحفظ | ✅ |
| التنقل: آية سابقة/تالية، النقر المباشر على أي آية أو رقمها | ✅ |
| تحكم بسرعة التلاوة + شريط تقدّم قابل للسحب | ✅ |
| بحث نصي غير متزامن عبر كل السور المتوفرة محلياً | ✅ |
| علامات مرجعية + استعادة آخر موضع قراءة تلقائياً | ✅ |
| لوحة تفسير تظهر عند النقر على آية | ✅ (بانتظار ملفات التفسير الفعلية) |
